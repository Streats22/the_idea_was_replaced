# The Idea Was Replaced

Game ideas inspired by *The Farmer Was Replaced*: programming games where your code does the work.

| Folder | What it is |
|---|---|
| [`delvework/`](delvework/) | **Current direction.** Programming dungeon crawler with a growing town: [concept](delvework/docs/CONCEPT.md) and [full roadmap](delvework/docs/ROADMAP.md). All C#: a deterministic core (`cd delvework && dotnet test`) and a Godot 4 .NET game in `delvework/game/` |
| [`rewild/`](rewild/) | Earlier concept: code a robot swarm to restore an ecosystem ([design plan](rewild/docs/DESIGN.md)) |
| [`drone-farm/`](drone-farm/) | Playable browser prototype (TypeScript + Vite) with its own Python-like interpreter. `cd drone-farm && npm install && npm run dev` |
